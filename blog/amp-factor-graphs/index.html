Message Passing: From Factor Graphs to GNNs — and What AMP Adds

A derivation-driven tour of belief propagation, the linear-Gaussian special case, and how graph neural networks learn those same messages — with an Approximate Message Passing twist at the end.

Approximate Message PassingGraph Neural NetworksProbabilistic MLFactor Graphs

What you'll learn

Message passing is the shared skeleton behind belief propagation, Kalman filtering, graph neural networks, and Approximate Message Passing. This article walks each step with full derivations, and ends with a runnable notebook.

The one idea behind everything

Every probabilistic model you will ever build can be drawn as a factor graph: a bipartite graph where round nodes are variables x1​,…,xN​ and square nodes are factors fa​ that couple them. The joint distribution factorizes as

p(x1​,…,xN​)=Z1​a∏​fa​({x}a​).

We want marginals p(xi​) — and the most efficient way to get them is to pass messages along the edges until the graph "agrees" with itself.

The sum–product message

Define a message from factor f to variable x as

μf→x​(x)=∫f(x,x′)μx′→f​(x′)dx′.

and from variable to factor as a product of incoming messages:

μx→f​(x)=g∈N(x)∖f∏​μg→x​(x).

After iterating to convergence, the belief at a variable is

b(x)∝f∈N(x)∏​μf→x​(x).

On a tree these beliefs are exactly the marginals. On loopy graphs, they are an approximation — usually a shockingly good one.

The linear-Gaussian special case

Let the model be x∼N(μ0​,P0​) and y=Ax+w with w∼N(0,R). In this case the messages stay Gaussian, and the sum–product rules collapse into Gaussian belief propagation:

μy→x​(x)∝exp(−21​(y−Ax)⊤R−1(y−Ax)),

and the belief update is closed-form:

x∗=P∗A⊤R−1y+⋯,P∗=(P0−1​+A⊤R−1A)−1.

Same equations, different names

This is precisely the Kalman update, the ridge-regression solution, and the Gaussian AMP update — just with different notation. When you see a Kalman filter in a robotics textbook, you're watching belief propagation in disguise.

From belief propagation to GNN layers

Now replace the fixed messages with learnable functions. A GNN message from node v to node u is:

mv→u(t)​=MSGθ​(hv(t−1)​,hu(t−1)​,evu​),hu(t)​=UPDϕ​​hu(t−1)​,v∈N(u)∑​mv→u(t)​​.

The aggregation ∑v∈N(u)​ is a sum-product over a local factor; the readout is a global factor; the whole thing is belief propagation with trained potentials. Below is the full mapping.

Chemistry interlude: molecules are already graphs

Drug discovery is a natural graph problem — atoms are nodes, bonds are edges. And because molecules are drawn chemically, it helps to write them chemically too. For example, sulfonation of benzene:

CX6​HX6​+HX2​SOX4​Δ​CX6​HX5​SOX3​H+HX2​O

The macro comes from the mhchem extension of KaTeX — the same extension that renders equilibrium arrows, oxidation states, and units:

CHX3​COOX−+HX2​O​CHX3​COOH+OHX−

For property prediction we don't need the drawing, just the connectivity. A GNN reads a SMILES string like CC(=O)Oc1ccccc1C(=O)O, builds the bond graph, and predicts logP — which is exactly what the notebook at the end of this article does.

What Approximate Message Passing adds

Belief propagation is exact on trees but intractable when the factor f couples O(N) variables — think compressed sensing with y=Ax+w and dense A. AMP sidesteps this by approximating the messages with a Gaussian state per variable:

x(t+1)=η(A⊤r(t)+x(t);θ(t))

with the residual updated by the famous Onsager correction:

r(t)=y−Ax(t)+δb(t)​r(t−1).

The correction is what makes AMP match the replica-predicted MSE — no other iterative solver gets this for free. And crucially, η(⋅) can be a learned soft-thresholding network — giving a GAMP-style network that we build in the GAMP-GNN project.

Hand-wavy? Don't be

The Onsager term is subtle. If you are implementing AMP from scratch, derive it from the state evolution recursion before adding learnable parameters — the blog companion to the gamp-gnn project page shows the full derivation.
