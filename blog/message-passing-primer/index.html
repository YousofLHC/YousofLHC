A Visual Primer on Message Passing — Why Molecules Think in Graphs

A gentle, heavily-illustrated introduction to message passing on graphs, built around molecules: from hand-drawn arrows to PyTorch Geometric in one sitting.

Graph Neural NetworksDrug DesignTutorial

For beginners

If this is your first time with GNNs, start here. We trade some rigor for intuition, then point you to the full derivation in the factor graphs article.

A molecule is a graph wearing a disguise

Every molecule is a labeled graph. Carbon, oxygen, nitrogen — nodes. Bonds — edges. The reason GNNs work on chemistry is that the language matches the data: a benzene ring stays a ring no matter how you twist it, and graph convolutions are equivariant to that twisting by construction.

The three-step dance

Each message-passing layer repeats one dance:

  1. Message — each neighbor vvv computes a vector "about you," mv→um_{v \to u}mv→u​.
  2. Aggregate — node uuu sums (or averages) all incoming messages.
  3. Update — node uuu fuses its old state with the aggregate.

hu(t)=σ ⁣(W(t)hu(t−1)+∑v∈N(u)mv→u(t))h_u^{(t)} = \sigma\!\left(W^{(t)} h_u^{(t-1)} + \sum_{v \in \mathcal{N}(u)} m_{v \to u}^{(t)}\right)hu(t)​=σ(W(t)hu(t−1)​+∑v∈N(u)​mv→u(t)​)

After TTT layers, node uuu "sees" everything within TTT hops. For small molecules, T=2T = 2T=2 covers the whole graph — which is why tiny models work so well here.

Why sum beats "molecular fingerprints" for big datasets

Fingerprints (ECFP, etc.) are hand-designed bit-vectors. GNNs learn the features to extract. The comparison is unfair in the best way:

PropertyECFP fingerprintGNN embedding
Featureshand-craftedlearned end-to-end
Invariancehash collisionsequivariant by design
Data needed~anybenefits from scale
Interpretabilityfixed bitsattention possible

Watch out for these three gotchas

  1. Redundant atom features. Duplicate features make readouts overweight hubs.
  2. Mean vs sum readout. For counting tasks (how many oxygens?) sum is essential.
  3. Training-test leakage by scaffold. Always split by scaffold, not randomly, when evaluating generalization to new chemistry.

Scaffold splitting

Random splits overestimate performance on drug discovery tasks — chemists never ask "how well does it memorize my existing library?" Split by Bemis–Murcko scaffold and watch your test MAE jump to a realistic number.
