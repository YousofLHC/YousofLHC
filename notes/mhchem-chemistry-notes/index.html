Chemistry for ML People: Bonds, SMILES, and Reaction Equations

The minimal chemistry toolkit an ML practitioner needs — SMILES notation, chemical reactions in mhchem, molecular graphs, and how RDKit talks to PyTorch.

No chemistry background needed

This note assumes zero chemistry. We focus on the representations that machine learning models actually consume: SMILES, molecular graphs, and reaction equations.

1 · SMILES in 60 seconds

SMILES is a one-line notation for molecules. Atoms are symbols, bonds are - (single), = (double), # (triple). Rings close by matching digits:

  • CCO → ethanol: \ceCH3CH2OH\ce{CH3CH2OH}\ceCH3CH2OH
  • c1ccccc1 → benzene (the c is lowercase aromatic carbon, 1 opens/closes a ring)
  • CC(=O)Oc1ccccc1C(=O)O → aspirin

2 · Writing reactions with mhchem

KaTeX's mhchem extension renders reactions directly inside LaTeX math. The syntax is close to how chemists actually write:

\ceCH3COOH+C2H5OH<=>[H+][−H2O]CH3COOC2H5\ce{CH3COOH + C2H5OH <=>[H+][-H2O] CH3COOC2H5}\ceCH3COOH+C2H5OH<=>[H+][−H2O]CH3COOC2H5

Equilibrium, temperatures, and labels all work:

\ceN2+3H2−>[Fecatalyst][450∘C]2NH3\ce{N2 + 3H2 ->[Fe catalyst][450 ^\circ C] 2NH3}\ceN2+3H2−>[Fecatalyst][450∘C]2NH3

Units too, via \pu:

\ce\pu0.5molL−1NaOH⇒half a mole of NaOH per liter\ce{\pu{0.5 mol L^{-1} NaOH}} \quad\Rightarrow\quad \text{half a mole of NaOH per liter}\ce\pu0.5molL−1NaOH⇒half a mole of NaOH per liter

Where you'll actually use this

  • Documenting molecule-level preprocessing in papers and reports.
  • Writing method sections that show your ADMET filters or synthesis routes.
  • Teaching notes like this one — the exact chemistry-flavored content a reviewer loves to see rendered correctly.

3 · From SMILES to graphs with RDKit

The pipeline every drug-ML project shares:

from rdkit import Chem
from rdkit.Chem import AllChem, Descriptors


mol = Chem.MolFromSmiles("CC(=O)Oc1ccccc1C(=O)O")
logp = Descriptors.MolLogP(mol)
fp = AllChem.GetMorganFingerprintAsBitVect(mol, radius=2, nBits=1024)


# atom + bond features → adjacency for the GNN
atoms = [a.GetSymbol() for a in mol.GetAtoms()]
bonds = [(b.GetBeginAtomIdx(), b.GetEndAtomIdx(), b.GetBondType().name)
         for b in mol.GetBonds()]

Then the resulting graph feeds the message-passing layers from the GNN notebook.

5 · Checklist before you feed molecules to a model

  1. Canonicalize SMILES — one string per molecule.
  2. Sanitize with RDKit (Chem.MolFromSmiles returns None on garbage).
  3. Featurize atoms (Z, hybridization, charge, H-count) and bonds (order, aromaticity).
  4. Split by scaffold — never random — for honest generalization numbers.
