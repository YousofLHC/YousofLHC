GAMP-GNN

Message Passing for Model-Based Compressed Sensing

2026activePyTorchPyGNumPyJAX
GitHub

Status

Under review at ICML 2026. Code is open source; the demo notebook runs the full pipeline in Colab.

The problem

Compressed sensing asks us to recover a sparse vector x∗∈RNx^* \in \mathbb{R}^Nx∗∈RN from M≪NM \ll NM≪N linear measurements:

y=Ax∗+w,w∼N(0,σ2I)y = A x^* + w, \qquad w \sim \mathcal{N}(0, \sigma^2 I)y=Ax∗+w,w∼N(0,σ2I)

Standard AMP iterates a denoiser η\etaη with a state evolution that tracks its performance. But the "right" denoiser depends on the true prior on xxx — which we don't know, and which is rarely exactly sparse.

The idea: make the denoiser a GNN

We treat the sparse structure as a graph prior: variables are nodes, measurement interactions are edges. Then we replace AMP's scalar soft-threshold η(⋅)\eta(\cdot)η(⋅) with a message-passing network that sees both the AMP state and the graph.

Per AMP iteration ttt, with residual r(t)r^{(t)}r(t) and prior state x(t)x^{(t)}x(t):

x^(t+1)=ηθ ⁣(A⊤r(t)+x(t),  G)\hat{x}^{(t+1)} = \eta_\theta\!\left(A^\top r^{(t)} + x^{(t)},\; \mathcal{G}\right)x^(t+1)=ηθ​(A⊤r(t)+x(t),G)

where ηθ\eta_\thetaηθ​ is our GNN. The Onsager term is retained analytically:

r(t+1)=y−Ax^(t+1)+⟨ηθ′⟩δ r(t)r^{(t+1)} = y - A \hat{x}^{(t+1)} + \frac{\langle \eta_\theta' \rangle}{\delta}\, r^{(t)}r(t+1)=y−Ax^(t+1)+δ⟨ηθ′​⟩​r(t)

Unfolding TTT iterations gives a deep, weight-shared network whose layers are AMP steps.

Why it wins

  • AMP convergence speed — state evolution predicts MSE, so we converge in far fewer iterations than Lasso or ISTA.
  • Learned priors — the GNN recovers block-sparse, tree-structured, and approximately-sparse signals that scalar thresholds miss.
  • Provably faster: on synthetic ℓ0\ell_0ℓ0​-sparse data we reach the AMP-Bayes oracle within 0.4 dB, using 3×3\times3× fewer iterations than vanilla GAMP.
