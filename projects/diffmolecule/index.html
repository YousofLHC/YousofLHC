Generative design on a graph

De novo design means sampling new molecular graphs, not retrieving known ones. We model the forward corruption as independent noise on fragments:

q(xt∣xt−1)=N ⁣(xt; 1−βt xt−1,  βtI)q(x_t \mid x_{t-1}) = \mathcal{N}\!\left(x_t;\, \sqrt{1-\beta_t}\, x_{t-1},\; \beta_t I\right)q(xt​∣xt−1​)=N(xt​;1−βt​​xt−1​,βt​I)

The reverse process is a learned GNN that predicts the denoising step — conditioned on a target property (e.g., predicted logP, binding score, synthetic accessibility):

pθ(xt−1∣xt,c)=N ⁣(xt−1; μθ(xt,t,c),  Σt)p_\theta(x_{t-1} \mid x_t, c) = \mathcal{N}\!\left(x_{t-1};\, \mu_\theta(x_t, t, c),\; \Sigma_t\right)pθ​(xt−1​∣xt​,c)=N(xt−1​;μθ​(xt​,t,c),Σt​)

Sampling anneals guidance strength with a classifier-free trick:

ϵ^θ=(1+w) ϵθ(xt,t,c)−w ϵθ(xt,t,∅)\hat{\epsilon}_\theta = (1 + w)\,\epsilon_\theta(x_t, t, c) - w\,\epsilon_\theta(x_t, t, \varnothing)ϵ^θ​=(1+w)ϵθ​(xt​,t,c)−wϵθ​(xt​,t,∅)

Design decisions that matter

  1. Fragment-level tokens — generating at the level of common fragments (rings, linkers) instead of atoms raises validity from ~40% to 91%.
  2. Equivariant message passing — the denoiser uses an E(n)-equivariant GNN, so rotamers and translations don't change the distribution.
  3. Guidance on the fly — the property head is a frozen MLP on pooled node features; no retraining when you swap the target.
