Kalman Filters from Scratch

A minimal, self-contained walk-through of the discrete-time Kalman filter — derive the predict and update steps, and see how the gain balances measurement noise R\mathcal{R}R against process noise Q\mathcal{Q}Q.

This is a bonus notebook that pairs with the article "Kalman and Bayesian Filters". It should render with the site styling — math via KaTeX, code via the site's code block.

mdcell 2

1 · The linear Gaussian state-space model

x_t = F x_{t-1} + w_t, \qquad w_t \sim \mathcal{N}(0, Q)$$ z_t = H x_t + v_t, \qquad v_t \sim \mathcal{N}(0, R)$$

codecell 3✓ executed #3
1import numpy as np
2

3F = np.array([[1.0, 1.0], [0.0, 1.0]])
4H = np.array([[1.0, 0.0]])
5Q = np.eye(2) * 0.01
6R = np.array([[1.0]])
7

8def kf_step(x, P, z):
9    # predict
10    x = F @ x
11    P = F @ P @ F.T + Q
12    # update
13    S = H @ P @ H.T + R
14    K = P @ H.T @ np.linalg.inv(S)
15    x = x + K @ (z - H @ x)
16    P = (np.eye(2) - K @ H) @ P
17    return x, P
18

19x = np.array([0.0, 1.0]); P = np.eye(2)
20x, P = kf_step(x, P, np.array([1.2]))
21print("Kalman gain K =", K[0])

2 · Why the gain matters

  • If R≫QR \gg QR≫Q (noisy measurements), the filter trusts the model; K→0K \to 0K→0.
  • If Q≫RQ \gg RQ≫R (unreliable dynamics), the filter trusts the measurement; K→1K \to 1K→1.
