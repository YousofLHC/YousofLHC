Graph Neural Networks for Molecular Property Prediction

A hands-on walk-through. We build a message-passing GNN from scratch in PyTorch, train it to predict octanol–water partition coefficients (logP), and inspect what the model has actually learned about molecular structure.

This notebook pairs with the article "Message Passing: The Glue Between Graphs and Molecules" — everything here is self-contained, so you can run it end to end.

1 · The message-passing update

A GNN treats a molecule as a graph G=(V,E)\mathcal{G} = (\mathcal{V}, \mathcal{E})G=(V,E) with atom features hu∈Rdh_u \in \mathbb{R}^dhu​∈Rd and bond features euve_{uv}euv​. Each layer ttt computes messages between neighbors and aggregates them:

mv→u(t)=MSG⁡(hv(t−1),hu(t−1),evu)m_{v \to u}^{(t)} = \operatorname{MSG}\left(h_v^{(t-1)}, h_u^{(t-1)}, e_{vu}\right)mv→u(t)​=MSG(hv(t−1)​,hu(t−1)​,evu​)

hu(t)=UPD⁡(hu(t−1),∑v∈N(u)mv→u(t))h_u^{(t)} = \operatorname{UPD}\left(h_u^{(t-1)}, \sum_{v \in \mathcal{N}(u)} m_{v \to u}^{(t)}\right)hu(t)​=UPD(hu(t−1)​,∑v∈N(u)​mv→u(t)​)

After TTT layers we read out a graph-level prediction via a permutation-invariant pooling (sum / mean / attention over node embeddings):

y^=READOUT⁡({hu(T):u∈V})\hat{y} = \operatorname{READOUT}\left(\left\{h_u^{(T)} : u \in \mathcal{V}\right\}\right)y^​=READOUT({hu(T)​:u∈V})

This is exactly the factor-graph view of inference we discuss in the blog: learned message functions playing the role of belief-propagation messages.

2 · One MPNN layer

The layer below implements a standard message passing + update block with sum aggregation, plus a residual connection. Note how similar this is to the mv→um_{v \to u}mv→u​ / huh_uhu​ equations above.

codecell 4✓ executed #2
1class MPNLayer(nn.Module):
2    def __init__(self, in_dim: int, out_dim: int):
3        super().__init__()
4        self.msg = nn.Linear(2 * in_dim, out_dim)
5        self.upd = nn.GRUCell(out_dim, in_dim)
6

7    def forward(self, h, adj, edge_attr):
8        # messages from neighbor v -> u (edge_attr decorates the message)
9        src, dst = adj.nonzero(as_tuple=True)
10        m = self.msg(torch.cat([h[src], h[dst]], dim=-1))
11        m = m * (edge_attr[src, dst].unsqueeze(-1) + 1.0)
12

13        aggr = torch.zeros_like(h)
14        aggr.index_add_(0, dst, m)              # sum over N(u)
15        h_next = self.upd(aggr, h)              # GRU update
16        return F.relu(h_next)

Reading out

After T=3T = 3T=3 layers, we pool node features and regress onto logP.

codecell 6✓ executed #3
1class MoleculeGNN(nn.Module):
2    def __init__(self, n_atom_feat=16, n_edge_feat=4, hidden=64, T=3):
3        super().__init__()
4        self.layers = nn.ModuleList(
5            [MPNLayer(hidden if i else n_atom_feat, hidden) for i in range(T)]
6        )
7        self.readout = nn.Sequential(
8            nn.Linear(hidden, hidden), nn.ReLU(), nn.Linear(hidden, 1)
9        )
10

11    def forward(self, h0, adj, edge_attr):
12        h = h0
13        for layer in self.layers:
14            h = h + layer(h, adj, edge_attr)   # residual message passing
15        pooled = h.sum(dim=0)                  # sum readout
16        return self.readout(pooled).squeeze()

3 · Training

For this demo we train on a small random split of the ESOL subset (800 molecules, featurized with RDKit). The loss is smooth-L1; we track both train and validation curves.

codecell 8✓ executed #4
1def train(model, feats, adj, edges, targets, val, epochs=40):
2    opt = torch.optim.AdamW(model.parameters(), lr=3e-3, weight_decay=1e-4)
3    loss_fn = nn.SmoothL1Loss()
4    train_loss, val_loss = [], []
5    for epoch in range(epochs):
6        model.train()
7        loss = loss_fn(model(*feats), targets)
8        opt.zero_grad(); loss.backward(); opt.step()
9        train_loss.append(loss.item())
10        model.eval()
11        with torch.no_grad():
12            vloss = loss_fn(model(*val[0]), val[1]).item()
13        val_loss.append(vloss)
14        if (epoch + 1) % 10 == 0:
15            print(f"epoch {epoch+1:>3d}  train {loss.item():.3f}  val {vloss:.3f}")
16    return train_loss, val_loss

5 · Take-aways

  • Message passing ≈ learned belief propagation. The mv→um_{v\to u}mv→u​ formulation in factor graphs (see the blog) is the blueprint for MPNN layers.
  • Locality wins. Summing over a molecule's neighborhood injects chemical validity into the inductive bias for free.
  • Next step: plug in an AMP-inspired soft-thresholding message function for molecules with noisy labels — a direction we explore in the GAMP-GNN project.
